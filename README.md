# Klasyfikator zmian skórnych - aplikacja Android wykorzystująca konwolucyjną sieć neuronową do klasyfikacji zmian skórnych
Aplikacja mobilna umożliwiająca klasyfikację zmian skórnych na podstawie zdjęcia użytkownika, wykorzystująca konwolucyjną sieć neuronową ResNet101, którą dotrenowano na danych z zbioru PAD-UFES-20.
